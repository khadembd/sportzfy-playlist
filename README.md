# 📺 Sportzfy Auto-Updated Playlist

Auto-updating IPTV playlist for **Sportzfy** app — generated by GitHub Actions every hour, with **live stream verification**.

## 📥 Playlist URLs (Televizo/VLC)

| File | Description |
|------|-------------|
| ⭐ [`sportzfy_hls_only.m3u`](output/sportzfy_hls_only.m3u) | All HLS streams, verified only |
| [`sportzfy_hls_all.m3u`](output/sportzfy_hls_all.m3u) | All HLS streams (incl. unverified) |
| 🔴 [`sportzfy_live.m3u`](output/sportzfy_live.m3u) | Live now (verified HLS) |
| 🔴 [`sportzfy_live_all.m3u`](output/sportzfy_live_all.m3u) | Live now (all HLS) |
| ⏰ [`sportzfy_upcoming.m3u`](output/sportzfy_upcoming.m3u) | Upcoming (verified HLS) |

Raw URL format:
```
https://raw.githubusercontent.com/khadembd/sportzfy-playlist/main/output/sportzfy_hls_only.m3u
```

## 🔧 How It Works

1. Fetches events from `live.sportzfy.life/api/upstream/events`
2. For each event, fetches watch page to extract per-event AES-GCM key `K`
3. Fetches `/api/upstream/playback/<parent>` → AES-GCM encrypted payload
4. Derives key: `SHA-256(K + "|lsp-v1|" + bucket)`
5. Decrypts to get stream URLs
6. Verifies each stream (HLS/DASH play-test)
7. Generates M3U playlists

## ⏰ Auto-Update

Runs every hour via GitHub Actions. Next run at :00 UTC.
